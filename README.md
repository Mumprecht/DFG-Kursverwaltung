# DFG-Kursverwaltung

Adress- und Kursverwaltung für die Drohnenfluggruppe Pfannenstiel (DFG).

## Projekt

Die DFG-Kursverwaltung dient zur Verwaltung von:

* Personen und Kontaktdaten
* Lehrgängen und Kursen
* einzelnen Kurstagen
* Ausführungsorten
* Teilnehmerzuordnungen
* Instruktoreneinsätzen
* Prüfungen
* Import und Export von Teilnehmerdaten
* Datensicherung und Wiederherstellung

Die Anwendung ist die Python-Neuentwicklung der bestehenden PowerShell-Anwendung `DFG_Pfannenstiel_Adress_und_Kursverwaltung.ps1`.

## Technische Grundlage

* Python 3
* PySide6 / Qt
* SQLite
* openpyxl
* PyInstaller

Die Anwendung wird plattformübergreifend für Windows, macOS und Linux konzipiert.
